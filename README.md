# ClipLaunch Website

A responsive three-page static website for ClipLaunch:
- `index.html` — homepage
- `privacy-policy.html` — privacy policy
- `terms-of-service.html` — terms of service

Shared design assets:
- `styles.css`
- `script.js`
- `assets/favicon.svg`

## Before publishing
1. Review the Privacy Policy and make sure its descriptions match the actual app, especially video processing, token storage, service providers, and deletion practices.
2. Replace `[INSERT YOUR STATE OR COUNTRY BEFORE PUBLICATION]` in `terms-of-service.html` with the appropriate governing-law jurisdiction.
3. Confirm the legal pages and support email are appropriate for your situation.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `cliplaunch-website`.
2. Upload all files and folders from this package, keeping the directory structure intact. `index.html` must be in the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/cliplaunch-website/`.

The page paths will be:
- `https://YOUR-USERNAME.github.io/cliplaunch-website/`
- `https://YOUR-USERNAME.github.io/cliplaunch-website/privacy-policy.html`
- `https://YOUR-USERNAME.github.io/cliplaunch-website/terms-of-service.html`

If you use a custom domain or a different repository name, the URLs will differ.
